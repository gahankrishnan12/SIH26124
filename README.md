# SIH26124: AI-Powered Mobile Urban Intelligence Platform

Smart India Hackathon 2026 — Problem Statement: **SIH26124**
> **AI-Powered Mobile Urban Intelligence Platform Using Public Transport Fleet**

---

## 1. Project Overview
This platform transforms public transit buses into mobile urban sensing units. Camera feeds from buses are processed using lightweight AI (YOLOv8) to detect both vehicles and road surface damage (potholes), geotag events onto transit corridors, and visualize urban mobility statistics on a decision-support dashboard.

---

## 2. Architecture & Pipeline

```
Road Video (Real Video / Known Test Sample / Backup Demo)
       │
       ▼
AI Inference Engine:
   ├── Vehicle Detection: YOLOv8n (COCO: car, bus, truck, motorcycle, person)
   └── Road Damage Detection: Pretrained YOLOv8 [REAL AI / DEMO SIMULATION Mode]
       │
       ▼
Event Generator (Timestamp + Simulated GPS Geotagging)
       │
       ▼
Storage (SQLite / JSON)
       │
       ▼
Analytics & Prototype Priority Scoring
       │
       ▼
GIS Map (Folium) & Streamlit Command Center
```

---

## 3. Real vs. Simulated Components (Full Disclosure)

| Component | Status | Details |
|---|---|---|
| **Vehicle Detection** | **Real AI** | Pretrained Ultralytics `yolov8n.pt` model detecting target COCO classes. |
| **Road Damage Detection** | **Dual-Mode** | **`REAL AI MODE`**: Inferences generated by verified fine-tuned YOLOv8 pothole model (`road_damage_yolov8.pt`).<br>**`DEMO/SIMULATION MODE`**: Explicitly labeled fallback if weights are deleted or forced for testing. |
| **Severity Calculation** | **Prototype** | Heuristic based on bounding-box relative area ($<1.5\%$ Low, $1.5-4.0\%$ Medium, $\ge 4.0\%$ High). *Prototype formula, not an official standard.* |
| **Video Input** | **Real Video** | Uses real road traffic video (`real_road_sample.mp4`) and known pothole test image (`test_pothole_big.jpg`). Backup synthetic video provided. |
| **GPS Geotagging** | **Simulated** | Interpolated transit corridor route coordinates (explicitly labeled in UI/data). |
| **Database & GIS** | **Real** | Real local SQLite database and interactive Folium GIS map. |

## 4. Pretrained Road Damage Model Details

* **Model Selected**: `samdutse/pothole-yolov8` (fine-tuned YOLOv8s) saved locally to `models/road_damage_yolov8.pt`.
* **Dataset Used**: Smartathon Pothole Dataset (Roboflow Universe).
* **Classes**: `{0: 'Pothole'}`.
* **Weights Size**: 22.5 MB.
* **Compatibility**: Ultralytics YOLOv8 PyTorch CPU runtime.

## 5. Measured CPU Performance Benchmarks (Empirical)

> **Hardware Context**: Standard CPU execution (Windows 64-bit, Python 3.13.5, Intel/AMD processor without dedicated GPU).

| Benchmark Metric | Measured Value | Notes |
|---|---|---|
| **Vehicle Model Latency** | **86.75 – 109.16 ms / frame** | `yolov8n.pt` (CPU) |
| **Road Damage Model Latency** | **140.20 – 175.50 ms / frame** | `road_damage_yolov8.pt` (CPU) |
| **Combined Dual-Model Latency** | **235.00 – 280.00 ms / frame** | Both models running sequentially on single CPU frame |
| **Dual-Model Inference Speed** | **3.8 – 4.3 FPS** | Dual YOLO CPU throughput |
| **Complete Pipeline Speed (inc. I/O & Encoding)** | **3.5 – 4.0 FPS** | End-to-end processing speed on CPU |
